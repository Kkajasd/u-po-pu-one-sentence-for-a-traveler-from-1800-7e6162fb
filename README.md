A program that writes one original sentence (195 characters) to `/output/entry.txt`, explaining the modern internet to a time traveler from 1800 using only words that existed in 1800 — a great hall of glass holding every letter, book, and song in the world, open to any stranger who walks in and asks a question. The sentence is fixed and deterministic — the same text on every run, no network, no input files. Built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The sentence it writes:

> Imagine one great hall of glass holding every letter, book, and song in the world, where any stranger may walk in, ask a question, and hear the whole world answer at once, in the blink of an eye.
